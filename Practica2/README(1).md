# BATALLAS POR TURNOS
Sistema desarrollado en Java para la simulación de batallas por turnos, considerando la velocidad como un factor para decidir la frecuencia de ataque.

##  Funcionamiento
Permite agregar personajes, validando que el nombre del personaje no se repita, el nivel de ataque este entre 10 y 100. La velocidad y agilidad esten entre 1 y 10, la defensa tiene que estar entre 1 y 50.

Permite modificar un personaje, busca y hace las las validaciones correspondientes para los nuevos olores.

Permite eliminar un personaje, necesita una confirmacion para eliminar el personaje deseado.

Permite visualizar los personajes registrados, mostrando los datos.


## INSTRUCCIONES

    Tener Apache-Netbeams instalado.
    Tener Java JDK 8 o superior.
    Abrir el proyecto y ejecutarlo.

OBSERVACIONES

    
    Se puede agregar las opciones faltantes, como los hilos para simular las batallas y las demás funcionalidades.
    Se podría cambiar los vectores de tamaño 25 por vectores o matrices dinamicos, que permitirian hacer el inventario de cualquier tamaño.
