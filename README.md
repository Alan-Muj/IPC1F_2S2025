# SISTEMA DE GESTION INTEGRAL
Sistema desarrollado en Java para la gestion integral para una tienda en linea, llamada "San Carlista Shop", con interfaz.

##FUNCIONAMIENTO
- Permite iniciar sesión por código y contraseña, solo usuarios registrados pueden acceder.
- Valida las credenciales según el tipo de usuario: Administrador, vendedor, cliente.
- Opcion para cerrar sesión.
- Cuenta con un modulo de administrador en donde se puede crear, modificar y eliminar vendedores.
- Permite la carga masiva de datos a través de un archivo CSV.

##INSTRUCCIONES
- Tener Java JDK 8 o superior.
- Ejecutar el archivo .Jar

## OBSERVACIONES
- Se puede agregar las otras opciones del modulo de administrador, así como los otros modulos.
- Se podría cambiar los vectores de tamaño 25 por arreglos dinámicos, que permitirian hacer el inventario de cualquier tamaño.
